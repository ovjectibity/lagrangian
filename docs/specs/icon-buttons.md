# Icon buttons

Provide reusable currentColor SVG assets for hyperlink, workloads, search,
panel expand/collapse, settings, live mode, charts, copy, wrap text, account,
API access, and credits/usage. Reuse the existing arrow-up-right asset for
hyperlink. Match the prototype's paths and stroke treatment.

Also include delete, logout, new, go back, and workload status icons for
in progress, scheduled, completed, and failed.

Include play/pause with toggled icon states and circular-arrow jump forward
and jump back icons matching the prototype transport controls.

Show each icon in an accessible Type-1 Button on the component showcase,
with persistent toggled selection and a visible descriptive label. Include
both expand and collapse states. Keep showcase styling in the route CSS.
