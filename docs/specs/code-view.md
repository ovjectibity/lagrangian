# Code view

Provide a read-only Monaco code view matching the dashboard panels.

- Left-aligned title and right-aligned optional subtext before controls.
- Optional header controls snippet for existing buttons and select controls.
- Built-in copy and word-wrap toggle buttons with accessible labels.
- Configurable code, language, and initial wrap state.
- Dark syntax highlighting, line numbers, responsive sizing, and scrolling.
- Initialise Monaco only in the browser and dispose the editor on unmount.
- Include an interactive example on `/components-showcase`.

Editing, file management, and language-server integration are out of scope.
