# Code view implementation

1. Install Monaco and configure its editor worker through Vite imports.
2. Add a composite code-view component with browser-only initialisation,
   reactive code/language updates, copy feedback, and a word-wrap toggle.
3. Keep shared styling in app.css and export through the component index.
4. Add a showcase using existing button and select controls.
5. Run the Svelte check and production build.
