# User popup

Provide a modal dialog that blocks interaction with the underlying screen.
Accept a header, body copy, and configurable primary/secondary CTA labels
and callbacks. Both CTAs use the existing Type-3 Button. Emphasise the
primary CTA with the selected treatment and place it after the secondary.
Expose bindable open state, close on either CTA or Escape, focus within the
dialog while open, and restore focus on closing through native dialog
behaviour. Backdrop clicks dismiss it as a secondary action. The action
footer has no divider. Include a showcase example.

Primary intent is configurable as positive (default, green background) or
negative (red background), with readable text and distinct hover treatment.
Show both intents in the showcase.
