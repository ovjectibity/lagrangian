# Cards view

Display a collection of existing Cards in a responsive grid based on the
view's available width. Use three equal-width columns from 960px, two from
600px, and one below 600px. Cards stretch to fill their grid cells and never
exceed three per row. Support an optional two-column maximum. Accept the
existing Card props as item data and show an empty-state message when empty.
Add an example on the component showcase.
