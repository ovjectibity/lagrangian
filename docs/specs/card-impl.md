# Card implementation

1. Add a Card composite with image, identity, status, and content props.
2. Style the thumbnail overlay and card sections in app.css using existing
   dashboard colours and typography.
3. Export through the component index and add showcase examples using an
   embedded schematic SVG as a sample thumbnail.
4. Add optional percentage/time progress below the footer and showcase it
   on the running card. CardsView inherits this through Card props.
5. Run Svelte checks and the production build.
