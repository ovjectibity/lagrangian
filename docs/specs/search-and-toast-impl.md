# Search bar and toast implementation plan

1. Record the shared contracts, accessibility behavior, and scope in a
   feature specification.
2. Add controlled SearchBar and bindable Toast Svelte 5 components.
3. Add their reusable styles to `client/src/app.css` and export the components
   from `src/lib/index.ts`.
4. Add an interactive showcase example with route-local presentation styles.
5. Run `npm run check` and `npm run build` from `client`.
